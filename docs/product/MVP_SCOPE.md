# MVP Scope & Boundaries
**Platform:** EKOTAI BOL (একতাই বল)  

---

## 1. Strictly In-Scope for Current MVP (Delivered)
- Full Next.js 15+ App Router application deployed on Vercel (`sin1` region).
- Integration with Firebase Auth (Google OAuth) + Cloud Firestore database.
- Anonymous public idea submission with district and category filters.
- AI screening simulator providing instant viability scores and duplicate checks.
- Public notice board with 5-star ratings and 3-way structured critique.
- 100 Taka voluntary micro-donation simulator with live masked transaction feed.
- Super Admin portal with moderation queue (Approve/Reject) and real-time project creation.
- Educational and governance blueprints for Bangladesh Labor Act 2006 and Universal Pension Pragati Scheme.

---

## 2. Deferred to Phase 2 (Out of Scope for MVP)
- Direct bKash / Nagad commercial merchant gateway integration (currently using transactional sandbox).
- Native Android application (APK build via Capacitor / React Native).
- Automated SMS OTP verification for donors.
- Formal AI LLM API token streaming (currently using deterministic rule-based copilot heuristics).
