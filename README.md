# EKOTAI BOL (একতাই বল)
> **একতাই শক্তি, উদ্যোগে পরিবর্তন।**  
> ডোমেইন: [ekoitaibol.com](https://ekoitaibol.com) | রিপোজিটরি: [github.com/gitinfobd/ekoitaibol](https://github.com/gitinfobd/ekoitaibol)

বাংলাদেশের ৬৪ জেলার মানুষের আইডিয়া, সম্মিলিত নাগরিক ভোটিং, স্বচ্ছ ১০০ টাকার মাইক্রো-জনতহবিল এবং নিজ জেলায় টেকসই প্রকল্প বাস্তবায়ন ও নিশ্চিত পেনশন-সুবিধার কর্মসংস্থান মঞ্চ।

---

## 🌟 প্ল্যাটফর্মের মূল ৫টি স্তম্ভ (Core Pillars)

1. **ফ্রি আইডিয়া জমাদান (Free Idea Submission)**:
   - যে কেউ Google OAuth দিয়ে এক ক্লিকে প্রবেশ করে নিজের এলাকার সমস্যা ও সমাধানের প্রস্তাব দিতে পারেন।
   - প্রস্তাবকের ফোন নম্বর ও নাম গোপনীয় থাকবে, যাতে পক্ষপাতমুক্ত নিরপেক্ষ মূল্যায়ন হয়।

2. **AI প্রজেক্ট কো-পাইলট ও স্ক্রিনিং (Internal AI Assistant)**:
   - ডুপ্লিকেট শনাক্তকরণ, ক্যাটাগরি ম্যাপিং এবং সাধারণ মানুষের প্রস্তাবকে ১-পেজ প্রজেক্ট প্রপোজালে রূপান্তর।

3. **পাবলিক নোটিশ বোর্ড ও নাগরিক রেটিং (Notice Board & Critique)**:
   - মাসের শেষ ১০ দিনে সব প্রস্তাব নোটিশ বোর্ডে ওপেন থাকে।
   - জনগণ ১ থেকে ৫ স্টার পর্যন্ত রেটিং দিতে পারে এবং ইতিবাচক দিক, ঝুঁকি বা উন্নয়ন প্রস্তাব (Upgrade Idea) লিখতে পারে।

4. **১০০ টাকার স্বচ্ছ জন-তহবিল (Micro-Crowdfunding & Live Ledger)**:
   - নির্বাচিত সামাজিক প্রকল্পে সাধারণ মানুষ ১০০ টাকা করে ঐচ্ছিক অনুদান দিতে পারেন।
   - রিয়েল-টাইম পাবলিক লেজার, যেখানে দাতার মোবাইল নম্বরের মাঝের ৫টি ডিজিট এনক্রিপ্ট (`0171****890`) থাকে।

5. **মাঠপর্যায়ে বাস্তবায়ন ও সর্বজনীন পেনশন ওয়েলফেয়ার (Sustainable Employment)**:
   - যে এলাকায় আইডিয়ার সূচনা, সেখানেই প্রথম বাস্তবায়ন।
   - স্থানীয় কর্মীদের জন্য বাংলাদেশ শ্রম আইন ২০০৬ অনুযায়ী নিয়োগ এবং **সর্বজনীন পেনশন স্কিম (প্রগতি প্যাকেজ)** বা ভবিষ্য তহবিলের যৌথ অনুদানের মাধ্যমে ৬০ বছর বয়সে নিশ্চিত সামাজিক নিরাপত্তা।

## 🛠️ প্রযুক্তি কাঠামো (Tech Stack)

- **ফ্রেমওয়ার্ক**: [Next.js 15+ (App Router)](https://nextjs.org/) + React 19
- **স্টাইলিং**: [Tailwind CSS](https://tailwindcss.com/) + Glassmorphism UX
- **আইকন**: [Lucide React](https://lucide.dev/)
- **কোড কোয়ালিটি**: Alibaba OpenCodeReview (OCR) অটোমেটেড ডিটেক্টর (`npm run ocr:check`)
- **সার্চ ইঞ্জিন ও এআই অপ্টিমাইজেশন (GEO)**: Structured JSON-LD Schema, AI-friendly `robots.txt` & `llms.txt`

## 🚀 লোকাল সেটআপ ও রান (Local Development)

```bash
# ডিপেনডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# কোড কোয়ালিটি ও আলিবাবা OCR ভেরিফিকেশন
npm run ocr:check

# প্রোডাকশন বিল্ড যাচাই
npm run build

# পুশ ও স্বয়ংক্রিয় ডিপ্লয়
npm run deploy
```

## 📜 আইনি ও সামাজিক নীতি (Legal & Anti-Fraud Guardrails)
- **চাকরি বিক্রয় নিষিদ্ধ**: অনুদানের বিনিময়ে চাকরি বা লটারির কোনো প্রতিশ্রুতি দেওয়া সম্পূর্ণ নিষিদ্ধ।
- **উপাত্ত সুরক্ষা**: বাংলাদেশ ব্যক্তিগত উপাত্ত সুরক্ষা আইনের নির্দেশনা মেনে দাতা ও প্রস্তাবকের সংবেদনশীল তথ্য গোপন রাখা হয়।
- **স্বচ্ছতা**: প্রতিটি খরচের বিপরীতে বৈধ ভাউচার নম্বর পাবলিক লেজারে সংযুক্ত করা আবশ্যক।
